# Neon Compass v1.0 — Roadmap des plans d'implémentation

Spec source : `docs/superpowers/specs/2026-07-19-neon-compass-companion-design.md`

Chaque plan livre du logiciel qui compile, passe ses tests et se démontre. Un plan n'est rédigé en détail qu'au moment de son exécution (le Plan 1 est prêt : `2026-07-19-plan-1-fondations.md`).

| # | Plan | Contenu | Dépend de | Jalon spec |
|---|------|---------|-----------|------------|
| 1 | **Fondations** | Projet Xcode (XcodeGen), design system synthwave + Liquid Glass, navigation 5 onglets (carte centrale), disclaimer/onboarding | — | Août |
| 2 | **Moteur de carte** | Viewer tuilé zoom/pan (CATiledLayer), POI en coordonnées normalisées, filtres/recherche, fiche POI glass, « Trouvé » → SwiftData, pins perso | 1 | Août |
| 3 | **Contenu & sync (infra)** | Firebase (SPM, protocoles `Core/`), modèles Firestore localisés miroir de `content/schema/`, cache SwiftData, Remote Config `contentVersion`, script CLI admin étendu (push réel, pas seulement dry-run) | 1 | Septembre |
| 3b | **Cheats** | Cartes cheats (tokens/glyphes manette), toggle PS5/Xbox, mode lecture plein écran, favoris | 3 | Septembre |
| 3c | **Guides** | Rendu Markdown natif, chapitres, cache hors-ligne | 3 | Septembre |
| 3d | **Actu (feed)** | Flux chronologique, cellules sponsorisées natives | 3 | Septembre |
| 4 | **Progression** | Checklists auto-générées, pourcentages, anneau néon, source de vérité unique carte↔listes, checklists trophées manuelles | 2, 3 | Septembre |
| 5 | **Comptes & communauté** | Sign in with Apple, profil/leveling (XP côté serveur), Cloud Functions `submitContribution`/`castVote`, App Check, Security Rules, anti-abus (cooldown, dédup géo, vélocité, shadow-ban), modération, suppression de compte | 2, 3 | Octobre |
| 6 | **Monétisation & localisation** | AdMob + ATT/UMP, StoreKit 2 « Pro » (paywall, entitlements, itinéraire optimisé, mode reste-à-faire, widgets, notifs suivies, thèmes), String Catalogs FR/EN/ES/IT/DE | 2–5 | Octobre |
| 7 | **Release** | Mode éditeur interne, QA iPad, contenu pré-sortie, fiches App Store ×5, TestFlight, soumission fin octobre | tous | Fin octobre |

**Note (22 juillet) :** le « Plan 3 » initial mélangeait infra de sync + 3 features UI indépendantes — scindé en 3 (infra) / 3b / 3c / 3d pour rester dans la taille d'un plan exécutable en une passe (cf. Plan 1 : 5 tâches, Plan 2 : 9 tâches + 3 rounds de bugs). 3b/3c/3d ne dépendent que de 3, pas les uns des autres — exécutables dans n'importe quel ordre une fois l'infra posée.

Hors v1.0 (rappel spec) : Live Activity, Apple Watch, auto-cochage Xbox, PSN (écarté), fil social, photos, Mac.
