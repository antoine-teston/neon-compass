# Plan 6a — Publicité (AdMob, ATT, UMP) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wire up the ad-funded revenue model — AdMob adaptive banners on list/feed screens, a capped interstitial, ATT + UMP consent gating — first sub-plan of "Monétisation & localisation" (roadmap Plan 6, split into Ads / Pro / Localisation per product decision 2026-07-23).

**Architecture:** A new `Core/Ads/` layer (protocols + AdMob-backed implementations, mirroring `Core/Auth/`/`Core/Community/`'s Firebase-behind-protocols convention — same discipline applies to the Google Mobile Ads SDK even though it isn't Firebase). Consent (ATT + UMP) gates ad loading entirely: no ad request of any kind fires before both are resolved. The interstitial's frequency cap is a pure, unit-tested policy function, per the spec's own testing section ("plafonnement des interstitiels" is explicitly called out as unit-testable logic).

**Tech Stack:** Google Mobile Ads SDK (SPM), Google User Messaging Platform SDK (SPM), Apple `AppTrackingTransparency`, existing Firebase Remote Config (interstitial frequency parameter).

## Global Constraints

- **Never a banner on the interactive map.** Spec §"Publicité": "bannière adaptative en bas des écrans de liste et du feed — jamais sur la carte en interaction." Only Feed, Cheats, and Guides list screens get a banner. `MapScreen` must never import or reference any ad type.
- **Interstitial: max 1 per session, never during a contribution flow, frequency via Remote Config.** No daily cap beyond the session cap is specified — don't invent one. "During a contribution" means: never show an interstitial while `ContributionSubmissionSheet` (Plan 5b) is presented, and never immediately before/after a `submitContribution` call in the same user action.
- **No ad request before consent is resolved.** ATT authorization status AND UMP consent status (for EU users) must both be settled — ATT via the system prompt, UMP via `requestConsentInfoUpdate`/the consent form if required — before `MobileAds.shared.start()` is called or any `GADBannerView`/interstitial load is requested. Without ATT opt-in, AdMob still serves ads (contextual, no IDFA) — this is expected and fine; what's not fine is requesting ads before the consent flow has even run once.
- **Never a native sponsored feed cell in this plan.** Spec §"Actu" mentions "cellules sponsorisées natives plafonnées" in the Feed alongside the banner — that requires a new ad-content type and an editorial/ad-ops workflow of its own scope. Explicitly deferred, not silently dropped — see this plan's Self-Review.
- **Google SDKs behind protocols in `Core/Ads/`** — features (`Features/Feed`, `Features/Cheats`, `Features/Guides`) never import `GoogleMobileAds` directly, only a wrapping SwiftUI view from `Core/Ads/`.
- **Swift 6, strict concurrency.** Any class holding a Google SDK handle as a stored property follows this codebase's established `nonisolated(unsafe)` pattern (precedent: `FirestoreProfileRepository`, `FirebaseAccountFunctions`, `RemoteConfigVersionProvider`).
- **App Privacy labels and the hosted privacy policy are NOT code** — spec §"5.1.2/ATT" ("Labels alignés sur les SDK réels, prompt ATT + UMP") is an App Store Connect configuration + a hosted document, tracked as a manual ops step (this plan's Task 5), same pattern as Plan 5c's Firebase Console manual-steps doc.
- **Verify exact SPM package coordinates before editing `project.yml`** — Google's Mobile Ads / UMP SDK distribution details change over time (product names, whether UMP ships bundled with the Ads SDK or as a separate package). Do not copy a URL from memory or from this plan without confirming it against Google's current official AdMob iOS SPM documentation first (Task 1 instructs this explicitly).
- **This plan does not touch StoreKit/Pro entitlements or localization** — those are Plan 6b/6c.

```swift
/// Abstraction over Google's User Messaging Platform (UMP) SDK — gates ad
/// serving on consent where required (EU/UK per Google's own region
/// detection), never bypassed (spec §RGPD: "Consentements pub (ATT/UMP) à
/// part" — this is a distinct, mandatory gate from account/profile consent).

    /// Returns true once it's safe to request ads (either no consent was
    /// required for this user's region, or consent was obtained). Returns
    /// false if the user is in a region requiring consent and declined, or
    /// the consent flow could not complete.
    func requestConsent() async throws -> Bool
}
```

```swift
import UIKit
@preconcurrency import UserMessagingPlatform

/// Implémentation réelle de ConsentProviding, adossée à UMP. Ne référence
/// jamais FirebaseApp.configure() ni MobileAds.shared.start() — ce fichier
/// ne fait que résoudre le consentement, l'appelant (NeonCompassApp)
/// décide quand démarrer le SDK Ads une fois ce signal obtenu.
final class UMPConsentProvider: ConsentProviding {
    func requestConsent() async throws -> Bool {
        let parameters = UMPRequestParameters()
        // Tagged for under-age-of-consent is never true for this app — no
        // COPPA-audience content, matches the rest of the app's adult/teen
        // GTA-companion positioning.
        parameters.tagForUnderAgeOfConsent = false

        try await UMPConsentInformation.sharedInstance.requestConsentInfoUpdate(with: parameters)

        guard UMPConsentInformation.sharedInstance.formStatus == .available else {
            return UMPConsentInformation.sharedInstance.consentStatus != .required
        }

        guard let rootViewController = await Self.topViewController() else {
            return false
        }

        return try await withCheckedThrowingContinuation { continuation in
            UMPConsentForm.loadAndPresentIfRequired(from: rootViewController) { error in
                if let error {
                    continuation.resume(throwing: error)
                    return
                }
                continuation.resume(returning: UMPConsentInformation.sharedInstance.consentStatus != .required)
            }
        }
    }

    @MainActor
    private static func topViewController() -> UIViewController? {
        UIApplication.shared.connectedScenes
            .compactMap { $0 as? UIWindowScene }
            .first?.windows
            .first { $0.isKeyWindow }?.rootViewController
    }
}
```

- [ ] **Step 1: Write `InterstitialCapPolicy.swift`**

```swift
import Foundation

/// Pure decision logic for whether an interstitial may be shown right now —
/// no AdMob/UIKit import, unit-testable without a device (spec
/// §"Stratégie de tests": "plafonnement des interstitiels" is explicitly
/// called out as unit-testable logic).
enum InterstitialCapPolicy {
    /// - Parameters:
    ///   - sessionShownCount: how many interstitials have already been shown
    ///     this app session (0 at launch).
    ///   - isDuringContribution: true while a contribution submission sheet
    ///     is presented — never interrupt that flow (spec point, Plan 5b).
    ///   - remoteConfigFrequency: the Remote Config-controlled frequency —
    ///     0 disables interstitials entirely (kill-switch style), 1 means
    ///     "eligible" subject to the session cap below, values above 1 are
    ///     reserved for a future "every Nth eligible moment" scheme and
    ///     currently treated identically to 1 (no such scheme exists yet —
    ///     see Self-Review).
    static func shouldShow(
        sessionShownCount: Int,
        isDuringContribution: Bool,
        remoteConfigFrequency: Int
    ) -> Bool {
        guard remoteConfigFrequency > 0 else { return false }
        guard !isDuringContribution else { return false }
        return sessionShownCount < 1
    }
}
```

```swift
/// Bannière adaptative — jamais sur MapScreen (Global Constraints de ce
/// plan). N'appelle jamais MobileAds.shared.start() elle-même.
struct BannerAdView: UIViewRepresentable {
    var adUnitID: String = "ca-app-pub-3940256099942544/2934735716" // AdMob's public test adaptive-banner ID — replace once provisioned.

    func makeUIView(context: Context) -> BannerView {
        let banner = BannerView(adSize: currentOrientationAnchoredAdaptiveBanner(width: UIScreen.main.bounds.width))
        banner.adUnitID = adUnitID
        banner.rootViewController = UIApplication.shared.connectedScenes
            .compactMap { $0 as? UIWindowScene }
            .first?.windows
            .first { $0.isKeyWindow }?.rootViewController
        banner.load(Request())
        return banner
    }

    func updateUIView(_ uiView: BannerView, context: Context) {}
}
```
