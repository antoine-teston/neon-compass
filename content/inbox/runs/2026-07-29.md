# Run data-scout — 2026-07-29

## L'incident réseau des deux runs précédents n'existait pas

Les runs du 21 et du 27 juillet concluaient tous deux à un blocage permanent en
403 sur les domaines de la liste blanche, et se rabattaient sur des extraits de
recherche — d'où des `source_date` approximatives et des faits jamais vérifiés
sur la page elle-même.

Vérification faite ce run, robots.txt en main puis requête par requête : c'était
**transitoire**. `www.gtaboom.com` autorise tout le monde
(`User-Agent: * / Allow: /`) et les cinq URLs qui avaient échoué répondent 200.
Aucun contournement n'était nécessaire ; ce qui manquait, c'était un réessai.

Ce run est le premier passé par `tools/content-cli/fetch-source.mjs`, qui
applique la liste blanche, réessaie les échecs transitoires, et préfère les flux
aux pages. **Zéro échec de récupération.**

## Doutes à trancher par un humain

1. **Le verrouillage régional des codes PS5 mérite peut-être mieux qu'une carte
   de fil.** C'est le seul fait de ce run qui peut coûter de l'argent à un
   joueur : acheter une boîte à l'étranger et se retrouver avec un code
   inutilisable. Un encart permanent dans une future section « acheter le jeu »
   servirait mieux qu'une actu qui descend dans le fil.
2. **L'expiration du code au Japon reste partiellement ouverte.** L'article
   dément le contresens sur le jeu de base, mais signale qu'un désaccord
   subsiste sur ce que couvre exactement la fenêtre de 170 jours. Le fait a été
   rédigé sur le point établi (le jeu de base n'expire pas) et laisse le reste
   de côté.
3. **La comparaison de prix vieillira mal.** Elle est vraie ce mois-ci ; elle
   n'aura plus de sens une fois les sorties de la rentrée passées. À retirer du
   fil vers octobre, ou à requalifier.
4. **`leonidaverse.com` publie très peu** (2 entrées dans son sitemap
   d'actualités, un mois en arrière). À conserver comme source de fond, pas
   comme source d'actu hebdomadaire.
