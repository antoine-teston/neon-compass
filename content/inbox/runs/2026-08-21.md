# Run de veille — 2026-08-21

## À lire en premier : `veille/recolte` n'a pas pu être supprimée par cette session

L'enveloppe de ce run ne fournit pas `gh` (binaire absent : `gh: command not
found`). Les écritures GitHub sont passées par les outils MCP `github` et,
pour la lecture seule, par `curl` avec `$GITHUB_TOKEN` contre `api.github.com`
(qui répond, `GET` compris). Mais la suppression de la branche de transport a
échoué par les trois chemins essayés :

- `git push origin --delete veille/recolte` → `HTTP 403`, RPC refusée ;
- `curl -X DELETE .../git/refs/heads/veille/recolte` avec `$GITHUB_TOKEN` →
  `403 Write access to this GitHub API path is not permitted through this
  proxy` ;
- aucun outil MCP `github` équivalent à `git/refs DELETE` n'est exposé (recherché
  explicitement — seuls `create_branch`, `delete_file`, `push_files`, etc.
  sont disponibles, rien pour une ref).

C'est exactement l'écart déjà signalé le 2026-08-19 : cette enveloppe cloud
n'offre aucun outil capable de supprimer une ref. Je le signale ici au lieu de
m'en remettre en silence au balayeur, comme le contrat le demande. Le filet
existe : `recolte-nettoyage.yml` supprime toute branche de transport âgée de
plus de deux heures, à ses passages de 05h15, 11h15, 17h15 et 23h15 UTC. La
branche a été déposée par le dispatch de ce run à 02:18:21 UTC ; elle sera
balayée au passage de 05h15 UTC, soit un séjour d'environ 3 h sur le dépôt
public. Un humain qui voudrait la faire disparaître plus tôt peut lancer
`recolte-nettoyage.yml` manuellement ou supprimer la ref directement.
