## Limite d'outillage constatée aujourd'hui

`gh` CLI absent de cet environnement de session planifiée — remplacé par les
outils MCP GitHub et, pour le déclenchement/scrutation du workflow, par
`curl` authentifié via `$GITHUB_TOKEN` (lecture seule). La suppression de la
**ref** `veille/recolte` (`DELETE git/refs/heads/...`) a échoué : la
passerelle proxy refuse les écritures REST hors du jeu de chemins autorisés
pour les outils MCP (`403 Write access ... not permitted through this
proxy`), et aucun outil MCP GitHub connecté n'expose la suppression de
branche. Le contenu du fichier `recolte.json` a été supprimé par commit sur
cette branche (donc plus présent dans son arbre courant), mais la branche
elle-même subsiste avec son historique. À traiter manuellement, ou à outiller
(ajouter un outil MCP de suppression de ref, ou un pas de nettoyage côté
`Récolte` elle-même) — signalé ici pour qu'un humain tranche.
