## Incident réseau (à signaler, pas contourné)

Cette session a un accès réseau sortant restreint par la politique d'egress de
l'environnement. Le fetch direct (outil `WebFetch` et `curl` via `Bash`) vers
les domaines suivants — pourtant sur la liste blanche du registre §7 — a été
rejeté avec un 403 au niveau du CONNECT proxy (confirmé via
`$HTTPS_PROXY/__agentproxy/status`, `recentRelayFailures`) :

- `www.rockstargames.com`
- `www.gtaboom.com`
- `gta.fandom.com`
- `leonidaverse.com`
- `gtacodes.io`
- `gta6.gg`
- `old.reddit.com` / `www.reddit.com` (rejeté aussi côté outil `WebSearch` :
  « domain not accessible to our user agent »)
- `www.ign.com` (test de contrôle hors liste blanche, même résultat)

Je n'ai pas tenté de contourner ce blocage (pas de proxy alternatif, pas de
retry agressif), conformément aux consignes du proxy. **À signaler à un
humain** : soit une politique d'egress de session trop restrictive à ajuster,
soit ces domaines sont à re-tester lors d'un prochain run.

**Contournement utilisé pour ce run** : l'outil `WebSearch`, restreint via
`allowed_domains` aux seules sources de la liste blanche (hors reddit.com,
qui est rejeté par l'outil lui-même), fonctionne et renvoie des extraits de
pages hébergées sur ces domaines autorisés. J'ai extrait les faits à partir de
ces extraits, en citant l'URL précise de la page source (jamais recopiée mot
à mot — toujours reformulée). Je n'ai donc pas pu lire les pages en entier ni
vérifier leur mise en page/contexte complet ; seulement les extraits fournis
par la recherche.

## Doutes à trancher par un humain

1. **Dates de source approximatives** : plusieurs pages consultées (wiki,
   pages produit) n'affichent pas de date de publication explicite dans les
   extraits de recherche — j'ai utilisé la date de consultation (2026-07-21)
   comme `source_date` faute de mieux. Le fait sur le trailer 3
   (`source_date: 2026-07-19`) est une estimation basée sur le contenu de
   l'article (mention du 19 juillet / finale Coupe du monde), pas une date de
   publication vérifiée — à confirmer en relisant l'article directement.
2. **Accès direct aux pages non vérifié** : tous les faits proviennent
   d'extraits `WebSearch`, pas d'une lecture complète des pages (`WebFetch`
   bloqué, cf. incident réseau ci-dessus). Un humain (ou un prochain run une
   fois le réseau débloqué) devrait relire les pages sources en entier pour
   vérifier qu'aucun contexte important n'a été perdu dans les extraits.
3. **r/GTA6 non couvert ce run** — à retenter au prochain run si l'outil de
   recherche autorise le domaine, ou via un accès manuel.
4. **Faits POI génériques** : les lieux listés (Vice Beach, centre-ville,
   aéroport, arène, hôtels) sont des repères de bande-annonce déjà largement
   connus de la communauté ; aucun scoop, juste une consolidation factuelle
   pour amorcer le schéma de contenu avant le jour J.
5. **Aucun cheat code réel n'a été inventé** — conformément à la règle, les
   3 faits « cheat » de ce run décrivent le *statut* (rien de confirmé) et des
   *anticipations* explicitement marquées `rumor`, jamais une séquence de
   touches fictive.
